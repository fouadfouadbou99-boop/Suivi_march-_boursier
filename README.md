# CMR Market Analytics Platform

Plateforme d'analyse automatisée des marchés financiers développée pour la Caisse Marocaine des Retraites (CMR).

Cette application permet de :

- Récupérer automatiquement les données de marché.
- Analyser l'évolution des indices boursiers.
- Calculer les indicateurs de performance et de risque.
- Générer des commentaires automatiques.
- Produire des rapports Excel.
- Fournir un tableau de bord interactif via Streamlit.

- Indices internationaux
